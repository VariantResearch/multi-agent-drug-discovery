# Gate 0 verification ledger

Every claim and every outcome in this dataset was verified against a
primary source fetched and read on 2026-10-22, during dataset
construction. Verdict "verified" means: the source was opened, the
identifier on the row resolves to that source, the claim text is a
paraphrase of what the source states, and the supporting_quote in the
input pack is a verbatim snippet of at most 25 words from the fetched
text. Quotes follow the text rendering of the fetched page (for example,
PubMed renders the Greek letter beta as "beta" or within words such as
"halphaCGRP", and chloride as "Cl(-)").

## Leakage limitation, stated honestly

Frontier models may already know these outcomes from training data.
These are famous programs: FOURIER, STRIVE, STEP 1, and EPOCH are
widely reported, and no input pack can remove knowledge a model already
carries. Gate 0 v1 is therefore a calibration and regression set for
reasoning and audit behaviour: whether agents build a case from the
cited evidence, whether the citation auditor and strike rules behave,
and whether scores are computed mechanically from sealed outcomes. It is
not a pristine blind test, and results on it must not be reported as one.

What the dataset does guarantee by construction:

- Input packs contain only material published before each case's
  evidence_as_of cutoff, which is set before the pivotal outcome was
  public.
- Input packs carry no outcome fields; madd.gate0.build_agent_pack
  refuses a pack that contains any sealed-only key.
- Each input pack carries a per-case forbidden_terms list of
  outcome-revealing words and phrases, and the leakage scan in
  madd/gate0.py checks every input text field against it. The dataset
  tests run this scan over all real packs.
- Outcomes are read only inside madd.gate0.score_run, at scoring time.

A case whose outcome leaks into its inputs despite these controls is to
be removed and recorded in REJECTED.md, per docs/PHASE0_SPEC.md.
