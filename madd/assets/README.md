# Vendored assets shipped with the console

- `3Dmol-min.js` - 3Dmol.js v2.5.5, a WebGL molecular visualization
  library by David Koes and contributors, BSD 3-Clause license
  (banner in `3Dmol-min.js.LICENSE.txt`). Source:
  https://3dmol.org - vendored so the console renders fully 3D
  structures without a network connection.
- `receptors/mtch2_alphafold.pdb` - the AlphaFold predicted model
  for human MTCH2 (entry AF-Q9Y6C9-F1, model v6; UniProt Q9Y6C9,
  303 residues; mean pLDDT 86.3). Data from the AlphaFold Protein
  Structure Database, licensed CC BY 4.0. It is a predicted model,
  not an experimental structure, and the file header says so.
